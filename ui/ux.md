# UI/UX Specification — FitnessTracker

## 🎨 Visual Theme
- **Primary background**: Pitch black (#000000)
- **Accent colors**: Eye‑catching neon palette (electric blue #00FFFF, neon green #39FF14, crimson red #FF3131, golden yellow #FFD700)
- **Typography**: Clean, professional sans‑serif (Inter, Roboto, or SF Pro)
- **Layout**: Phone‑friendly proportions (responsive scaling, large tap targets, minimal clutter)

## 📱 Mobile Responsiveness
- All components scale smoothly on mobile screens
- Sidebar collapses into bottom navigation bar on phones
- Buttons and inputs sized for thumb reach
- HUD timer and sliders optimized for portrait mode

## ✨ Animations & Transitions
- Page transitions: smooth slide‑in/out animations
- Component transitions: translucent fade + scale effects
- Workout completion: confetti burst animation
- Status indicators: glowing pulse effect (green = connected, red = disconnected)

## 🧭 Navigation
- Clear bottom navigation bar (Home, Routines, Logs, Profile)
- Swipe gestures for page transitions
- Consistent iconography (minimalist, line‑based icons)

## 🎉 Feedback & Interactions
- Toast notifications for saves and errors
- Confetti + celebratory animation after “Finish & Log”
- Mood emojis selectable when logging workouts (🔥 😅 😴)
- Supabase connection status: glowing circle (green/red)

## 🪄 Professional Polish
- Translucent overlays for modals
- Smooth hover/tap feedback (color glow or ripple)
- Consistent spacing and padding for a premium feel
