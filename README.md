# FitnessTracker

A customizable fitness tracking app built with **Vite**, **Supabase**, and **Capacitor**.  
Deployed on [Vercel](https://vercel.com).

## Features
- Track workouts and progress
- Supabase backend for secure data storage
- Responsive UI built with modern web tools

## Getting Started
1. Clone the repo
2. Install dependencies: `npm install`
3. Run locally: `npm run dev`

## Deployment
Environment variables (Supabase keys) are managed securely in Vercel.
